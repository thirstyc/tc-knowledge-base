## Overview

Cépage blanc / Italie

Piccolit

Vin blanc doux du Frioul. Alcool moyennement élevé, acidité moyenne. Doux, complexe. Rare, onéreux. Le trésor du Frioul.

Également appelé: Picolit
Alcool typique: 12–14 %
Acidité: Moyenne
Origines: Frioul (Italie)
