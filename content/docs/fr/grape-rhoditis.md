## Overview

Cépage blanc / Grèce

Rhoditis

Vin blanc grec. Acidité élevée, teneur en alcool faible à moyenne. Frais, vif, minéral. Base de retsina. Simple, net, rafraîchissant. Le vin blanc grec de tous les jours.

Également appelé: Roditis
Teneur en alcool typique: 10–12 %
Acidité: élevée
Origines: Grèce, Patras
